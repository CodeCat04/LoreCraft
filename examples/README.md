# Example project

**[The Saltmarch.lorecraft](The%20Saltmarch.lorecraft)** is a small sample world. Download it and open it with **File > Open** to see what a LoreCraft project looks like. It's the same world as **Open sample world** on the start screen.

What's inside:

- **A wiki:** 17 pages about Cray Landing and the Lamplighters Guild. They have characters with infoboxes, places, a guild, events, categories, and links between them all. Open **Wren Halloway** for a full character page.
- **A book,** *The Unlit Road*, with chapters and scenes. They're linked to the characters and places they mention, with point of view, cast and dates filled in.
- **Family trees and relationships.** See **Atlas > Family tree** and **Atlas > Graph**.
- **A timeline** built from the dates on the pages. See **Atlas > Timeline**.
- **Planted mistakes for the consistency checker.** Run **Consistency > Check now** to find them.

Your own projects stay separate. Changes to this file only reach it when you save.
